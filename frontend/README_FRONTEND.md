# Frontend viewer

This static frontend reads `run_summary.json` generated by `12_build_run_summary_v4.py`.

## Run

From the project root:

```bash
cd frontend
python3 -m http.server 8000
```

Open:

```text
http://localhost:8000
```

Then either:

- click **Load sample run**, or
- click **Import run JSON** and select `outputs/run_sma_gwl2.0/run_summary.json`.

## Downloads

`12_build_run_summary_v4.py` copies generated CSV/EPW/JSON files into:

```text
frontend/public/downloads/<run_id>/
```

The frontend uses each file's `download_href` field for the Download button. The local source path is still displayed for traceability.

## Notes

- XMY profile scores are displayed as independent metric cards because each stress profile has a different unit.
- The carpet plot uses the real 12 × 24 monthly-hourly average temperature matrix when available; otherwise it falls back to a synthetic diurnal approximation.
- The Crawley-style comparison panel shows BPS cooling metrics when available and weather-file CDH comparison otherwise.
